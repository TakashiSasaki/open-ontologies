## Restoration and later upgrades

The native image, both Go binaries, worker, source bundles, exact service/policy
configuration, environment record and SHA-256 manifest are stored outside Git.
The previous fork image/source and cold data backups remain available. Restore
the matching configuration as well as binaries; the old fork version does not
match this adapter's upstream-version guard. Preserve writes made after a backup.

For a new upstream release, select its image and matching extracted worker,
update the version/hash guard, review tool changes, repin only reviewed schema
grants and rerun the isolated suite. No Rust patch needs to be carried for the
interface improvements. Engine-level upstream limitations still require an
upstream change or an explicitly chosen separate engine.
