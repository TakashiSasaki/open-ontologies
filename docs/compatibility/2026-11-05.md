## Findings and chosen changes

| Priority | Reproduction | Adaptation |
| --- | --- | --- |
| P0 | Native policy check allows a bare/unparseable target when an ASK fails | Whole-term IRI binding; query/input failures are indeterminate MCP errors; preserve successful-rule deny-overrides/default-allow semantics |
| P0 | Native JSON error text can have `isError: false` | Promote the known top-level error contract, preserving content, precision and valid negative findings |
| P1 | Native SHACL preflight only walks targetClass NodeShapes | Enumerate all shapes and declaration references in a private parser; check declared IRIs through the native read-only preflight; retain parse/bound checks and mark coverage limits |
| P1 | Raw versus bracketed parameters disagree between native preconditions and effects | New read-only action inspection; safe advisory applicability; normalize schemas/bindings only inside private plan simulation; report incompatible live schemas |
| P1 | PDDL predicate `a` differs from the initial state's rdf:type | Normalize supported ASK predicates in private copies; mark output execution unready because the compiler remains incomplete |
| P2 | Core health hides absent optional resources | Container inspection plus read-only application probes, with explicit tool/mode scope and snapshot freshness |
| P2 | Dry-run alignment says auto-applied | Separate auto-apply candidates, zero actual applications and score interpretation |
| P2 | Temporal empty result looks like a whole-store answer | Explicit named-graph-only scope; default graph excluded |

`onto_shacl_check` is a declaration/bound preflight, not a full SHACL syntax,
target-reachability or conformance proof. It accepts files only through the
configured read-only data roots. Logical shape discovery and property paths
are bounded; unsupported/malformed/cyclic cases are reported rather than
counted as an entirely checked successful result.

Registry inspection uses a fixed Python script with isolated interpreter mode,
fixed SQL, SQLite `mode=ro`/`query_only` and an explicit read snapshot. It has no
client-supplied path, SQL or executable. Registry and graph snapshots are
separate stores: these checks are **advisory, not atomic authorization**.

## Remaining engine work

1. Integrate policy evaluation with **every actual mutation** under an engine
   transaction/coordinator. A proxy check or proxy mutex cannot cover native
   background writers, alternative endpoints or the SQLite/RDF-store boundary.
2. Replace ad-hoc action grounding with a shared RDF-term binding model. Live
   `onto_action_apply` still uses the unchanged stored native schema. Private
   normalized simulation can succeed while a legacy live schema remains
   incompatible; `live_iri_binding_compatible` makes that distinction explicit.
   Literal/partial-IRI effects and stochastic plans are deliberately unsupported
   by this adaptation rather than silently given different semantics.
3. Complete PDDL constants, injective/reversible symbol mapping, literal sorts,
   general SPARQL translation and solver qualification. Current output is
   exploratory, `execution_ready: false`; no Fast Downward run was qualified.
4. Engine DL diagnostics/budget behavior remains upstream. Existing patch
   candidates 0001/0002 are retained; new standalone candidate 0003 preserves the
   narrow `a` fix and a regression for future submission. See the patch README
   for exact validation boundaries. No patch is applied to the live engine.
5. Optional binaries/models/crosswalk resources need deliberate installation and
   functional qualification if those features are wanted. Their absence does
   not disable ordinary built-in validation, graph queries or reasoning.

Logical storage IDs, complete migration/backups, full W3C conformance, larger
ontologies, concurrency with real writes and solver end-to-end tests remain
separate follow-up work. This task does not install every optional solver,
rename existing data identifiers, rewrite existing registries or delete audit
files from the shared native `/tmp` directory.
